# FPGS Project Page

Academic project page for:

**FPGS: Flow-Free Prior-Guided 3D Gaussian Splatting for Endoscopic Surgical Scene Reconstruction**

## GitHub Pages

1. Upload `index.html`, `README.md`, and the `assets/` folder to the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Open `https://jinlin04.github.io/FPGS/`.

## Before public release

- Replace the draft PDF with the final paper or preprint.
- Update BibTeX after acceptance.
- Add public code and video links when available.
